# 🚨 Interactive Clickbait & Fake News Headline Detector

A simple Python and Machine Learning project that analyzes news headlines in real-time and detects whether they are **Reliable** or **Clickbait**.

---

## 🚀 Features
* **Text Classification:** Uses TF-IDF vectorization and Logistic Regression (`scikit-learn`).
* **Real-time Detection:** Instantly flags sensationalized or misleading headlines.
* **Interactive Terminal Loop:** Test any custom headline live.

---

## 💻 How to Run in Google Colab

1. Open [Google Colab](https://colab.research.google.com/).
2. Create a new notebook.
3. Paste and run the Python script to start testing headlines!

---

## 🛠️ Tech Stack
* Python 3.x
* Pandas
* Scikit-Learn
